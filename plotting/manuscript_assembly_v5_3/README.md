# Frozen manuscript figure assembly V5.3

This directory contains the code lineage for the approved 20-figure collection:

- main figures: Fig01-Fig06;
- Extended Data: ED01-ED06;
- Supplementary figures: SI01-SI08.

`nature_figure_trial/` retains the final builders, freeze manifests, figure
contracts and QA notes. Generated PDF/PNG/SVG/TIFF artifacts are intentionally
excluded from this code-only staging area.

The builders expect the curated V5.3 processed source-data atlas to be available
outside this directory. That input will be connected to the separate Source Data
release during the portability/reproduction pass.
