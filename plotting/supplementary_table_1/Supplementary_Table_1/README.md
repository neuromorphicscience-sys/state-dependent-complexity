# Supplementary Table 1 delivery package

## Scientific role

This table documents the structural-feature quality-control boundary supporting
SI1. It records the archived descriptive distribution of 26 fields and makes the
two zero-variance fields explicit. It contains no inferential statistics and does
not provide evidence for dynamical leverage.

## Files

- `Supplementary_Table_1.xlsx` - primary editable table. The first sheet is the
  manuscript table, the second preserves the raw source values, and the third
  records provenance and interpretation boundaries.
- `Supplementary_Table_1.docx` - landscape Word version for direct insertion into
  Supplementary Information.
- `Supplementary_Table_1.pdf` - visually reviewed one-page landscape reference.
- `Supplementary_Table_1_source.csv` - unchanged source-table copy.
- `Supplementary_Table_1_caption.txt` - manuscript-ready title, caption and notes.
- `DELIVERY_MANIFEST.json` - artifact checksums and source provenance.
- `build_supplementary_table_1.py` - reproducible builder.

## Writing boundary

The safe manuscript statement is that `dendrite_length` and `dendrite_nodes` have
zero variance in the archived PFC cohort and are uninformative for variance-based
analyses. Identifier and categorical-code summaries are retained for auditability
but must not be interpreted as continuous biological quantities.

Before submission, the authors should confirm the source-atlas unit conventions if
units are to be added to the table. The present version deliberately preserves the
archived numeric scale without assigning undocumented units.
