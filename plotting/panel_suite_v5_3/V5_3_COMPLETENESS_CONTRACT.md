# V5.3 completeness contract

V5.3 keeps the same **no scientific evidence loss** rule as V5.2.

## Guaranteed scope

- No datasets are dropped.
- No stage outputs are intentionally deduplicated away.
- No statistics, confidence intervals, p-values, or analysis tables are modified.
- The package only changes **rendering style**, **text handling**, **marker filling**,
  **heatmap appearance**, and **physical axis-body normalization**.

## Included stage families

- Early stage: Stage1 / Stage1B / Stage2 / Stage3
- Main analysis: Stage4A / Stage4 integrated / Stage5A / Stage5B / closure extensions
- High-value biological datasets: SynPhys and OpenScope

## Expected usage

Use V5.3 to regenerate clean leaf panels for manual main-figure assembly.
Final manuscript composition remains a separate manual or semi-manual step.
