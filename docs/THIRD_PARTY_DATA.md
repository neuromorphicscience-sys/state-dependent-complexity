# Third-party data and code-license boundary

The top-level GPL-3.0-only license covers only the authors' source code and
documentation. It does not relicense third-party datasets.

The code expects separately obtained data from resources including Allen Cell
Types, Allen Visual Behavior, SynPhys, Steinmetz Neuropixels and OpenScope/DANDI.
No raw third-party dataset is included in this code-only directory. Users are
responsible for obtaining those data from their original providers and following
the applicable provider terms, citation requirements and controlled-access
conditions.

Python dependencies are referenced by package name and version constraint; their
source code is not vendored here and remains under each package's own license.
