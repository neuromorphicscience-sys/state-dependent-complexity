# Stage 4A reproduction warning

This directory is the self-contained historical Stage 4 source package. Its
`configs/stage4.json` records a legacy/general configuration and was not the
runtime configuration that produced the frozen Stage 4A results.

For Stage 4A reproduction, use:

`../stage04a/formal_frozen/configs/stage4a.json`

The confirmed Stage 4A values are population 4,096, 512 elites, 3,072 offspring,
512 random injections, six generations and two selected/unselected-node swaps
per offspring.
